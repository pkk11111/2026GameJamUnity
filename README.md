# pawgatory

pawgatory 是一款使用 Unity 6.2 开发的 2D 横版动作探索游戏。玩家操控小狗，在多层地图中寻找宝箱、获得身体部件和能力，并通过舍弃部件或承担负面效果支付传送代价，在探索与战斗中不断调整自己的能力组合。

开发环境：**Unity 6.2（6000.2.9f1）**，URP 2D、Input System、uGUI/TMP、Wwise；目标平台为 Windows。

正式入口为 [MainMenu](Assets/Scenes/Frontend/MainMenu.unity)，进入 [MainLevel](Assets/Scenes/Gameplay/MainLevel.unity)。在这两个场景中点击 Play 默认从主菜单开始。获取完整仓库及 Git LFS 资源后，用指定 Unity 版本打开项目。

接手开发请先读 [AGENTS.md](AGENTS.md)，再读 [当前交接](docs/handoffs/controller.handoff)。交接包含目录索引、关键组件、运行与构建方法、待办及实际验证范围。

## 已实现内容

### 角色与能力

- 基础移动、跳跃和咬击。
- 身体部件与能力联动：获得腿后可以二段跳，获得手剑后使用剑击，获得普通尾巴后可以冲刺，获得火焰尾后可以释放缓慢飞行、持续造成伤害的火焰团。
- 三个共用构筑槽，支持领取、舍弃和满槽替换；普通尾与火焰尾互斥。
- 角色外观与动作动画随实际持有部件变化，包含移动、跳跃和攻击表现。

### 宝箱与传送

- 宝箱随机三选一奖励，包含身体部件、回血、提高生命上限和增加攻击力。
- 排除已持有的同款部件，取消后保留候选；领取和替换统一结算。
- 普通传送门每次使用都需从三项代价中选择一项，支持舍弃部件、降低玩家数值或强化全图敌人。
- 代价预览与不可选提示，拒绝会导致生命归零的支付；取消或落点无效时不扣费，成功抵达后提供短暂保护。

### 地图与战斗

- 多层平台地图，已布置 9 个宝箱、4 个普通传送门、按钮机关、阻挡门和 7 处地刺。
- 单按钮控制一扇或多扇门，关门时检测玩家占位；两处支线条件入口经首次确认解锁后，本局保持开放。
- 13 只普通敌人和 1 只终点精英，包含巡逻、追击、返回、接触伤害和死亡处理。
- 咬击、剑击与火焰伤害，以及作用于本局全图敌人的生命和攻击强化。
- 地刺扣血与弹开反馈；探索往返时保留已领取宝箱、机关和敌人的本局状态。

### 界面与游戏流程

- 主菜单、开场故事、Esc 暂停与恢复、死亡后自动重开当前关卡；暂停逻辑独立于调试界面。
- 玩家生命条、身体与三槽 HUD、奖励与代价卡牌、敌人头顶血条和生命数值。
- 跟随玩家的交互与教学提示，显示附近宝箱、按钮和传送门的操作。
- 存活玩家碰到顶部绿色终点门后进入胜利状态，播放白屏转场并淡入结局画面。

### 美术与音频

- 已接入地图背景与前景、角色身体组合动画、普通敌人与精英动画、宝箱贴图、卡牌图标及 UI 美术。
- 已集成 Wwise，并接入移动、跳跃、战斗、受伤、死亡、宝箱、机关、传送、菜单和卡牌等音效，以及探索与精英相关音乐。
- 游戏通过统一音频入口调用声音，音频后端与玩法逻辑分离。
