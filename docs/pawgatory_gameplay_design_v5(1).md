## 1. 游戏定位、故事与 Regrowth 主题

### 1.1 一句话概念

一只只剩头的小狗在地狱中寻找自己的身体。它让躯干、腿、手与尾巴重新长出来，却又要为了穿越空间或进入隐藏挑战主动舍弃部分身体，在残缺、适应和再生之间找到重返人间的道路。

### 1.2 玩家目标

探索一张固定多层地图，利用奖励、开关、门和收费传送推进，最终击败第三层出口前的精英，存活到达出口。

不要求集齐全部部件、不检查完整身体、不要求固定流派。基础身体足以完成主线与必要返程；额外部件和技能提供便利与不同打法。

### 1.3 三个设计支柱

| 支柱 | 玩家感受 | 玩法落点 |
|---|---|---|
| Grow／生长 | 找回身体的一部分 | 头部开局、固定躯干教学、部件奖励与外观显现 |
| Shed／舍弃 | 为继续探索，主动失去一部分自己 | 收费传送的代价卡、条件支线入口、满槽替换 |
| Regrow／再生 | 缺失后适应，再让身体长回 | 缺失期间的挑战、部件重新入池、支线再生奖励 |

主题闭环：**缺失 → 生长 → 舍弃 → 以残缺形态适应 → 再生**。身体图标与技能绑定只是表达手段；关卡必须提供真正缺失一段时间后再获得的机会。

首版不增加再生材料、经验条、逐帧组织生长、跨局等级或技能树。同一部件再次获得就是再生，额外收益复用回血与数值增益。

## 3. 基础身体、操作与生命

### 3.1 永久基础

| 状态 | 可用动作 | 生命规则 |
|---|---|---|
| 只有头 | 移动、一段跳；没有攻击 | 只处于安全教学，不放敌人、危险地刺、致死坑或扣血门 |
| 头＋躯干 | 移动、一段跳、基础咬击 | 正式生命启用，受伤可致死 |
| 基础身体＋构筑项 | 基础动作与对应增强能力 | 失去手、腿、尾巴或技能不关闭生命系统 |

头与躯干不占槽、不可舍弃。躯干只在首箱获得一次，不进入普通奖励池。领取躯干时，以配置的初始最大生命初始化并填满当前生命；之后不得通过部件再生重复初始化满血。

安全教学建议约10–20秒。不能绕过躯干箱进入正式危险区；获得躯干后开放教学出口或正式危险。

### 3.2 基础操作

基础移动、基础跳跃永久保留。躯干获得后始终有普通攻击：无双手咬击，有双手剑击。双手不是基础攻击的存在条件。

沿用统一输入适配器。白盒移动/跳跃/冲刺/交互键可作为测试参考，正式键位以项目 Input Action 统一配置为准；R测试回起点不自动成为正式免费传送或检查点功能。

## 4. 三个通用构筑槽

### 4.1 统一占槽规则

用户明确故事流程：正式新局只有头、三个空构筑槽，Items与EverOwnedItems为空、没有Arms、不能剑击。教学箱获得躯干不占槽；只有随后从宝箱候选确认领取“手（剑）/Arms”，原子奖励成功才占一个槽、显示手剑并开启剑击。打开/预览/取消不改槽位、不授予能力；不保证每个随机箱必出手剑，不自动加独立Sword。

独测T08自动获得手臂只是测试捷径，不作为故事开局。教学躯干不填构筑槽；无需另造剑槽或独立剑卡。

**部件与独立可保留技能共用三个总槽位。** 每项通常占一槽。

| 构筑项 | 占槽 | 是否可舍弃 | 规则 |
|---|---:|---|---|
| 双腿整体 | 1 | 是 | 双腿一起出现/消失，不拆左右腿 |
| 双手＋自带基础剑整体 | 1 | 是 | 手与剑是一项，不额外占武器槽 |
| 普通尾巴 | 1 | 是 | 提供冲刺 |
| 火焰尾巴 | 1 | 是 | 同一部件提供喷火，不再为其附带能力收第二个槽 |
| 独立喷火技能 | 1 | 是 | 是一个独立构筑项；不因有空闲身体部位而免费获得 |
| 未来独立可保留技能 | 1/项 | 是 | 接同一槽位服务，未实现不投放 |
| 头、躯干、基础移动/跳跃/咬击 | 0 | 否 | 永久基础 |
| 即时回血、最大生命/攻击增益 | 0 | 否 | 即时结算到本局数值 |
| 本局负面 | 0 | 否 | 持续到本局结束，不是可舍弃项 |

一项自带的能力不会再独立计槽。例如“双腿＋二段跳”一槽；“双手＋剑击”一槽。独立领取的喷火是另外一项，确实占槽。

### 4.2 槽位示例

| 当前构筑 | 已用槽 | 再拿独立喷火时 |
|---|---:|---|
| 双腿＋双手＋普通尾巴 | 3 | 必须替换其中一项，不能变成四项 |
| 双腿＋普通尾巴 | 2 | 喷火占第三槽，可共存二段跳、冲刺与喷火 |
| 双手＋独立喷火 | 2 | 还可领取一项部件或独立技能 |
| 双腿＋火焰尾巴＋双手 | 3 | 已有喷火来源，不再重复投放独立喷火 |
| 无双腿，但双手＋普通尾巴＋独立喷火 | 3 | 支线领取腿再生仍需替换一个旧项 |

最后一个例子必须覆盖：**缺少某部件并不一定有空槽**，独立技能也可能占满三槽。

### 4.3 身体部件与技能表

| 来源 | 获得效果 | 移除效果 | 表现 |
|---|---|---|---|
| 双腿 | 启用二段跳 | 禁用二段跳，保留一段跳 | 成对腿生长/消失 |
| 普通尾巴 | 启用冲刺 | 禁用冲刺 | 普通尾巴生长/消失 |
| 双手＋剑 | 普攻改剑击 | 普攻恢复咬击，手和剑一起消失 | 手剑模块显示/隐藏 |
| 火焰尾巴 | 启用喷火 | 禁用该来源喷火 | 火焰尾巴生长/熄灭 |
| 独立喷火 | 启用喷火，不额外长出尾巴 | 禁用喷火，保留原有身体 | HUD技能图标与嘴部火焰表现 |

普通尾巴与火焰尾巴属于同一部位，互斥。选火焰尾巴替换普通尾巴，失去冲刺、获得喷火；反向替换则反过来。尾巴互换是一槽到一槽的替换，必须确认，不先移除。

火焰尾巴与独立喷火是同一种能力的两种发放形式，不叠加伤害、不重复占有。为减少首版工作量，一个实际奖励池只启用其中一种喷火发放形式；若采用火焰尾巴，部件与喷火一起占一槽；若采用独立技能，喷火自身占一槽。公共槽位规则必须支持两种形式，不能把独立技能当成不占槽的即时Buff。

### 4.4 攻击与姿态

有手时剑击、无手时咬击；没有腿也能挥剑。喷火是独立技能输入/能力，不替代普通攻击，也不依赖双手。无手支线只检查双手是否缺失，不把它误写为完全禁止攻击。

剑击及其他攻击不消耗耐久，不因累计使用次数而损坏或失去能力；攻击伤害、冷却与身体权限仍按原规则。

删除旧版独立站立奖励与独立剑奖励。站立可以作为手剑状态的表现，不再占槽。首版所有组合沿用同一稳定碰撞体，身体显隐不改变重力、基础速度、跳高或通行尺寸。

## 5. 生长、舍弃与再生

### 5.1 生长

奖励最终确认后一次性更新持有项、能力权限、身体显隐、HUD及宝箱状态。部件可使用缩放、亮起和通用粒子表现，不要求每个组合完整重画。

### 5.2 舍弃

部件舍弃：移除构筑项、禁用能力、隐藏对应部件。独立技能舍弃：移除构筑项、禁用技能，不删除无关身体。都释放一个槽。

不额外附带扣血，不产生可回收残肢。不在传送后自动返还。若正在冲刺/攻击时失去来源，玩家模块清理运行状态，避免残留速度、伤害区或动画事件。

### 5.3 再生

舍弃项重新进入合法奖励池。再次获得腿、手、尾巴时显示再生文案，并恢复相应身体与能力。独立技能可重新获得，但不伪称某个未获得的身体部件长回。

本局记录“曾持有项”即可，不另做经验系统。首获显示“长出双腿”，曾获得而当前缺失时显示“双腿再生”。记录在成功提交时更新，取消和看卡不更新；新局清空。

### 5.4 奖励布置

> 本节为旧V5稿；冲突处以最新[combat_rules](combat_rules.md)及AGENTS§0为准，不继续实现旧奖励/落坑方案。

主路至少保留一个位于实际代价后的未消耗奖励点，可配置优先提供“曾持有且当前缺失”的部件。两条支线分别提供腿/手再生组合奖励。玩家可选择其他收益，不强制复原，但关卡必须让再生实际可发生。

已领取宝箱不因舍弃补货，不制作无限领取资源。

## 6. 宝箱、奖励池与替换

### 6.1 教学箱

第一只箱子固定给躯干，使用一张教学卡，不做三张相同选项。取消保持头部，仍可再次打开；确认后正式生命、咬击与教学出口同步启用。

### 6.2 普通奖励

> 本节为旧V5稿；冲突处以最新[combat_rules](combat_rules.md)及AGENTS§0为准，不继续实现旧奖励/落坑方案。

| 类别 | 条目 | 占槽/结算 |
|---|---|---|
| 部件 | 双腿、双手＋剑、普通尾巴；已实现火焰尾巴 | 一项一槽 |
| 独立技能 | 已实现的独立喷火等 | 一项一槽，和部件共享总容量 |
| 恢复 | 回复当前生命 | 0槽，最多回复到当前最大生命 |
| 身体增益 | 增加最大生命 | 0槽；是否同时补血由统一配置说明 |
| 战斗增益 | 增加玩家攻击 | 0槽，作用于已实现的攻击体系 |

普通箱从当前可投放定义中无放回抽三张不同卡，默认等概率。不保证每类各一张。再生优先箱先保留一个有效再生候选，其余两张抽取。

已持有同款项排除；同源技能不重复；未实现项排除。另一种尾巴可出现，但明确需要替换当前尾巴。满血回血允许出现，显示当前没有即时恢复收益。

即时奖励至少配置回血、最大生命与攻击三个不同定义，确保满构筑仍能形成三选一。数值由配置管理，不能把常见100 HP等数字当作已批准初始值。

### 6.3 候选固定

第一次打开后保存卡组；取消不刷新。旧候选因其他领取变成重复项时，只修复该位置，不整组重抽。其余候选保留，修复后不得重复。

支线固定的部件再生候选若在未领取期间已从别处获得该部件，改为同一卡位的强化回血，仍与生命上限、攻击两张不同，不给重复部件。满血时如实显示无当前恢复收益。

### 6.4 满槽替换

- 未满三槽：确认新项，加入一项。
- 满三槽：展示当前三个构筑项，包含独立技能，指定替换哪一项。
- 尾巴互换：直接确认替换旧尾巴，不额外要求第四槽。
- 即时效果：直接结算，不要求腾槽。
- 组合奖励：部件加入/替换与附加回血同一次提交。
- 取消：不移除旧项、不加技能、不回血、不消耗宝箱。

替换必须先验证新项、旧项和全部效果，再原子提交。不能先长腿或先回血，之后才发现没有槽位；不能把独立喷火排除在替换列表之外。

## 7. 收费传送与生命代价安全规则

### 7.1 基本规则

除InspectionDoor1、InspectionDoor2外，所有传送门每次使用都须从[combat_rules第11.3节传送代价池](combat_rules.md)随机三选一支付，包括首次、返程、同层与重复使用；两扇支线门沿用指定部件单卡确认，不另抽随机代价。成功后消费卡组，下次重抽并再次收费；取消与无效落点不收费，没有免费应急传送通道。终点若为传送门同样收费，单纯胜利触发区不因此改造成传送门。只有躯干教学完成、角色存活、运行阶段允许交互时可使用。

代价定义由当前可舍弃构筑项和本局负面组成，包括独立技能舍弃。卡组为三个不同条目。

有构筑项时优先保证至少一张有效舍弃卡；其他两张从剩余定义抽取。无构筑项时从负面定义抽取。至少保留一个可执行选项；不允许菜单出现三张都不能选却没有继续方式。

### 7.2 代价池

抽卡系统共用（用户确认）：传送与宝箱使用同一套抽卡系统，通过不同卡池配置区分奖励池与传送代价池，复用等概率无放回三选一、卡片展示、取消保留候选与失效位置补位逻辑。每个宝箱/传送入口各自保存候选，不共用同一副卡组；奖励确认执行领取，传送确认执行支付与迁移。已有差异作为各自池的校验与结算规则保留：宝箱领取后消耗，传送成功后下次重抽；代价卡仍执行灰卡/全灰修复与生命安全校验，不将这些限制套到满血回血奖励。复用系统不合并两种池、不新建第二套UI或随机抽取实现，不改变InspectionDoor单卡确认。

> 本节为旧V5稿；冲突处以最新[combat_rules](combat_rules.md)及AGENTS§0为准，不继续实现旧奖励/落坑方案。

| 代价 | 结算 | 可选择条件 |
|---|---|---|
| 舍弃双腿 | 移除腿与二段跳 | 当前持有双腿 |
| 舍弃双手 | 移除手剑，恢复咬击 | 当前持有双手 |
| 舍弃当前尾巴 | 移除其对应能力 | 当前持有该尾巴 |
| 舍弃独立技能 | 移除技能、释放一槽 | 当前持有该独立技能 |
| 扣当前生命 | `damage = ceil(currentHP × 0.20)` | `currentHP - damage > 0` |
| 降低生命上限 | `loss = ceil(maxHP × 0.10)`；`newMax = maxHP - loss`；`newHP = min(currentHP, newMax)` | `newMax > 0 AND newHP > 0` |
| 降低玩家攻击 | 本局叠加减益 | 结算后仍满足配置的有效攻击下限 |
| 增加敌人生命 | 全图存活敌人含精英，按原生命比例同步当前生命 | 可产生实际合法效果 |
| 增加敌人攻击 | 全图存活敌人含精英 | 可产生实际合法效果 |

敌人强化不复活死敌，作用持续至本局结束。数值幅度、取整与叠加方式除明确公式外仍由平衡配置冻结。后续新生成敌人应从本局状态继承相同强化。

### 7.3 致死卡不可选：计算与示例

生命代价以**实际将执行的结算结果**判断，不看标题或仅按百分比粗略判断。禁止通过先执行扣血、再把角色生命夹到1来伪造安全代价。

| 状态 | 代价计算 | 结果 |
|---|---|---|
| 当前HP=1 | 扣血 `ceil(1×20%)=1`，结果0 | 卡牌置灰，无法确认 |
| 当前HP=2 | 扣血 `ceil(2×20%)=1`，结果1 | 可选择 |
| 最大HP=1，当前HP=1 | 扣上限 `ceil(1×10%)=1`，新上限0 | 卡牌置灰，无法确认 |
| 最大HP=2，当前HP=2 | 扣上限1，新上限1，当前HP压到1 | 可选择 |
| 最大HP=100，当前HP=1 | 扣上限10，新上限90，当前HP仍1 | 可选择，不把上限扣除量当当前扣血量 |
| 最大HP=100，当前HP=95 | 新上限90，当前HP压到90 | 可选择 |

示例100不是批准的角色初始值。降低生命上限本身不删除躯干。

### 7.4 灰卡、合法卡与不刷卡

候选的“可展示”与“可执行”分开。生命定义可以显示为灰卡，说明“代价会导致死亡”，但鼠标、键盘、手柄与业务提交全部拒绝该选择。灰卡不是选择后才失败。

卡组首次成功展示后固定。若三张全不可执行，仅随机选1个位置，从当前池中未显示且可执行的非生命效果卡等概率补入1张，其余两张与顺序保持；不优先舍弃，不给免费传送。完整明细与概率见combat_rules第11.6至11.8节。

再次打开时重新计算灰卡状态与实际金额；失去某技能造成候选不存在时修复该卡位。生命灰卡不因点击或取消而自动重抽。每次成功传送消耗本轮卡组，下次使用重新抽取。

低血量、最大生命最低值、没有构筑项时都应有有效非生命代价。数值配置不能同时把全部非生命定义封死；这是关卡交付验收约束。

### 7.5 传送事务

1. 唯一交互系统选定门，验证运行阶段、存活状态和躯干条件。
2. 打开暂停的代价菜单，显示三张卡及是否可选。
3. 确认前验证目标、落点和选项，再模拟结算；生命代价必须仍安全。
4. 验证失败则留原地，显示原因，不收费、不耗卡组、不移动。
5. 成功后一次性应用代价、清理运动并传送，更新身体与HUD。
6. 抵达获得原方案0.5秒保护，覆盖伤害类型由统一伤害系统配置。
7. 关闭菜单，释放锁，恢复玩法；动画和音效不再次扣费。

重复确认只能成功一次。献祭代价不被受伤无敌或未来盾抵消。菜单暂停防止确认期间被敌人改变生命；提交时仍必须复验，不能只信打开菜单时的HP。

**本版删除“选择致死代价后原地死亡”的正常路径。** 若已有旧服务意外产生致死结果，必须回滚整笔交易并报告异常，不能继续传送或把死亡当成合法选择。

## 8. 两条支线的共同进入与入坑规则

> 本节为旧V5稿；冲突处以最新[combat_rules](combat_rules.md)及AGENTS§0为准，不继续实现旧奖励/落坑方案。

### 8.1 支线定义

| 支线 | 类型 | 缺失要求 | 会失去什么 | 成功后的再生选项 |
|---|---|---|---|---|
| `SIDE_LEGLESS_PUZZLE` | 无腿解谜 | 当前没有双腿 | 二段跳 | 双腿再生＋回血 |
| `SIDE_ARMLESS_TRAVERSAL` | 无手跑酷 | 当前没有双手 | 剑击，恢复咬击 | 双手再生＋回血 |

两条支线均位于主地图旁路，不控制主线门。各自拥有独立ID、入口、安全重试点、目标、奖励与完成状态，不共享同一个“挑战已完成”布尔值。

### 8.2 入口条件门与进入资格判定

两条支线前各设置一扇入口条件门，未获入场许可时有实体碰撞、阻挡通行。玩家从外侧靠近检测区自动弹出单卡菜单，无须按E。InspectionDoor1为无手支线：持有双手时询问是否舍弃双手连剑，否则询问是否开启挑战；InspectionDoor2为无腿支线：持有双腿时询问是否舍弃双腿，否则询问是否开启挑战。确认后只移除对应项（如持有），门消失并解除实体；取消只关闭UI，离开范围再次靠近才重新检测。状态来自唯一玩家状态，不自动拆除、不收无关部件。门打开不授予永久资格，实际跨入继续校验；它不同于普通按钮门和层间收费传送。

进入请求必须满足：

- 已取得躯干、当前生命大于零、整局尚未胜利或失败。
- 当前可以交互，不在另一笔菜单/传送/奖励提交中。
- 玩家接近本支线入口，入口绑定的挑战区域与安全入口点有效。
- 这次是从外部进入，不能站在奖励区或碰到任意Trigger直接授予挑战资格。
- 未完成时满足本支线指定的缺失条件，或通过确认事务舍弃指定部件。

| 进入时状态 | 未完成支线的处理 |
|---|---|
| 无腿支线＋持有腿 | 提示“舍弃双腿进入”；确认后移除双腿并允许进入 |
| 无腿支线＋没有腿 | 确认“开启挑战”且资格有效才进入，不扣血或额外舍弃 |
| 无手支线＋持有手 | 提示“舍弃双手进入”；确认后手剑消失、恢复咬击，再允许进入 |
| 无手支线＋没有手 | 确认“开启挑战”且资格有效才进入，不要求先长手再拆掉 |
| 玩家取消 | 不移除部件、不改变位置、不启动尝试 |
| 入口/安全点无效 | 拒绝进入，不先收费或拆部件 |
| 已完成但未领奖 | 开放奖励访问，不再次要求拆部件；奖励卡组保持 |
| 已领奖 | 可按地图允许参观/通行，无新奖励、不重复强制拆部件 |

条件按身体项判断，不按槽位空缺或角色贴图判断。无腿不等于没有所有移动技能；无手不等于不能攻击或没有喷火。入口不能自动移除其他部件、独立技能或负面效果。

### 8.3 舍弃与进入的原子顺序

从外侧靠近入口 → 检查身体条件/入口和落点 → 显示单项舍弃或开启挑战确认 → 复验持有状态（变化时更新菜单、要求再次确认）→ 提交必要的指定部件移除与本次许可 → 隐藏门/解除实体 → 确认实际跨入区域 → 启动该次尝试。取消后须离开检测区再靠近。

入口不是随机代价三选一，不能制造三张相同“无腿”或“无手”选项，也不叠加主线层间传送费用。入口许可必须绑定这一个支线和这一次进入，不能开一次门就让后来持有部件的玩家绕过校验。

如入口采用走入区域而非立即移动，确认后的过门检查仍需复验缺失条件；取消或未跨入不计完成。若实现采用一步移动到安全入口，验证失败不能先移除部件。

### 8.4 挑战中部件约束

无腿挑战未完成期间保持无腿；无手挑战未完成期间保持无手。对应再生箱只在完成后开放，挑战内部不放提前补回该部件的其他宝箱。

合法保留的其他部件和独立技能不禁用。若未来有外部途径在中途恢复被限制部件，本次尝试判无效并结束；已获得的部件不再强制拆除，仍可退出，回入口按正常资格重试。

成功后解除本支线的缺失约束，允许领取再生部件并离开。不能因为长回腿/手而把已赚取奖励撤销或堵住出口。

### 8.5 “落坑”的检测区域

为避免把入口和失败坑混淆，场景单独配置三种区域：

| 区域 | 职责 | 触发结果 |
|---|---|---|
| `EntryZone` | 确认玩家实际从外部进入此支线 | 校验许可与缺失条件，启动尝试 |
| `FallFailZone` | 放在挑战落坑底部/区域底线，检测失败跌落 | 活跃尝试失败，执行落坑处理 |
| `FinishZone` | 放在有效终点，检测完成 | 校验当前尝试、目标与缺失条件，再解锁奖励 |

`FallFailZone`使用独立长方形Trigger覆盖真实坑底，可复用简单触发器。不要用摄像机是否看见玩家、玩家Y小于0、角色图像脚底、全图统一底线判失败。判断应基于正式玩家根组件/碰撞体与其当前活动支线ID。

空地正常下落、落在下一平台或走向物理出口都不是落坑失败。区域要贴合各支线，不能把下层主路误包进去；同一支线多个坑可引用同一个挑战ID。

### 8.6 落坑后的处理

1. 检测本次活动尝试进入该支线失败区，取得尝试锁；同一跌落只处理一次。
2. 立即结束本次尝试，不解锁新奖励，取消未完成的本次目标进度。
3. 按统一地形伤害配置扣一次落坑伤害，实际受伤保护/重复事件由伤害系统统一处理。
4. 若生命归零，整局失败，不执行局部恢复或奖励。
5. 若存活，移动到本支线入口安全重试点，清速度、冲刺/击退状态和危险区重叠。
6. 腿/手仍保持已舍弃状态，不返还部件、不清负面，不恢复满血。
7. 在重试点重新满足入口条件并启动新的尝试，不再向已经缺失的部件收费。

落坑伤害可致死，与“生命献祭卡不能致死”是不同规则。伤害幅度使用配置项，不新增默认100HP或固定百分比承诺。控制器可复用传送位置设置，但它只返回当前支线起点，不连接其他层，不代替收费传送。

### 8.7 退出、重试和进度边界

| 事件 | 本次尝试 | 已舍弃部件 | 机关/奖励状态 |
|---|---|---|---|
| 未完成时主动步行退出 | 结束本次尝试 | 不返还 | 本支线临时谜题复位；未解锁奖励 |
| 未完成时落坑且存活 | 本次失败，允许重试 | 不返还 | 临时目标复位；不重抽奖励/不发奖 |
| 完成但取消领奖 | 成功保持 | 保持当前状态 | 完成与固定卡组保持，可稍后领奖 |
| 已领奖后再次进入 | 不启动可领奖新尝试 | 不强制舍弃 | 领奖状态不重置 |
| 普通层间往返 | 不清整局完成记录 | 正常保留 | 主地图状态与支线完成/领奖保持 |
| 整局死亡重开 | 全部支线重置 | 回头部开局 | 全图状态、负面与奖励重置 |

本支线临时开关/门必须是独立对象，失败复位不能把主线门也切回初始状态。全图既有机关仍保留往返状态。退出路线始终物理可走，不能要求再付一项随机代价。

同一物理帧若碰到失败区与终点，失败/死亡优先，不发奖；奖励安全区不得与失败Trigger或地刺重叠。一次成功、一次领奖均以稳定ID锁定，重复触发不重复结算。

## 9. 支线A：无腿解谜挑战

### 9.1 体验目标

**有腿 → 主动舍弃 → 失去二段跳 → 用基础跳与开关寻找通路 → 腿再生或其他强化收益。**

主要挑战是机关顺序和通路观察；基础跳路线清楚，不把高难跑酷变成主负担。

### 9.2 最小布局

入口安全平台 → 开关A → 路线/门变化 → 开关B或回返路径 → 终点奖励台 → 步行出口。

建议复用现有“一按钮切换两门”的逻辑：门D1/D2初始互补，操作后各自取反，让玩家观察哪条路能通。只用两扇门和一到两个已有按钮，不新增推箱、重力翻转、投掷部件等谜题系统。

按钮数量与门关系可以在实际白盒内简化。所有必要开关用基础跳可达；咬击、剑或喷火都不作为必要开门条件，按钮由交互输入控制。

### 9.3 入坑与完成判定

- 入口资格：`HasBodyCore && Alive && !HasLegs`，以及第8节通用条件。
- 触及本区域失败坑：本次解谜尝试失败，按共用落坑流程处理，复位本支线临时开关/门。
- 完成需同时满足：本次从正确入口开始、尚未失败/退出、仍无腿、配置的目标机关已达成、玩家实际进入终点安全区。
- 只碰奖励箱或站在门后，不替代上述完成条件。
- 首次合法完成设 `Completed=true`，解锁独立奖励箱；后续不重复完成/发奖。

主路线无需二段跳或冲刺，无相关能力时也可完成。可保留其他构筑项，但不能用它们直接绕过完成目标条件。

## 10. 支线B：无手跑酷挑战

### 10.1 体验目标

**有手剑击 → 主动舍弃双手 → 保留咬击、失去剑击 → 通过平台与陷阱路线 → 手再生或其他强化收益。**

无手是入场代价，跑酷本身突出移动、起跳时机与落点观察。不要宣称手决定移动能力，也不要增加“无手走得更快”等未设计收益。

### 10.2 最小布局

入口安全平台 → 短缺口 → 一段高低平台 → 地刺危险段 → 终点安全平台与奖励箱 → 步行返回路。

长度优先控制为一个小旁路，使用现有实体平台、地刺和固定路线。不新增移动平台、攀爬、抓边、限时竞速、墙跳或跑酷分数系统；复杂度来自平台组合和安全落点。

至少有一条仅用基础移动和一段跳可完成的路线。保留腿或尾巴可以降低难度、提供安全捷径，但不是必须。跑酷失败风险通过落坑与地刺提供，首版不放强制战斗门、不要求挥剑破障碍，也不要求喷火。

### 10.3 入坑与完成判定

- 入口资格：`HasBodyCore && Alive && !HasArms`，以及第8节通用条件。
- 进入前持有手时，确认舍弃整组手剑，普通攻击立即切回咬击。
- 地刺受伤/击退本身不自动判挑战失败；只要仍活着、没有进入失败坑，可以继续。
- 触及失败坑：本次跑酷失败，按共用落坑流程回本支线入口；已舍弃手不返还。
- 完成需同时满足：本次从入口合法启动、没有失败/退出、仍无手、进入终点安全区。
- 基础版路线只设入口与终点，不新增跑酷检查点；地图必须防止从主路直接跳到领奖点。若布局无法封住旁路，可加一个中段经过Trigger作为必要到达标记，不增加奖励或复活点。

已有独立喷火可在无手时使用，不影响资格；但它不能替代终点路线完成判定。无手支线不是“所有攻击禁用挑战”。

现有按钮支持一对一与一对多门，各门独立取反。前两层设计意图为一个按钮对应一个门；最后一层有一个按钮控制两个指定门的组合。实际引用以场景数组为准。

主线跨层机关与两条支线机关分开注册。支线失败复位仅恢复本支线临时门/按钮，不触及主线机关。门关上时不得把玩家嵌入；关门占用由程序统一处理。

### 11.4 主线通行原则

- 基础身体、移动、一段跳、咬击可完成必要主路和返程。
- 额外能力用于捷径、便利或安全，不是主线必需。
- 主路攻击机关可用咬击，不要求双手剑击或喷火。
- 门移除后原Ground不能残留阻挡。
- 传送落点与支线重试点必须有足够站立空间，不重叠敌人、地刺或失败区。
- 美术保持平台顶边、墙边、实体厚度，镜头能看见落点与危险。

## 12. 战斗、地形伤害与胜负

> 本节为旧V5稿；冲突处以最新[combat_rules](combat_rules.md)及AGENTS§0为准，不继续实现旧奖励/落坑方案。

### 12.1 战斗

普攻只有咬击和手剑两种，统一攻击输入，由当前身体状态切换。喷火使用统一技能输入，不由卡片UI或动画自行读键。

判定范围、伤害、冷却、击退、受伤保护时间都由配置管理。动画与代码只有一个伤害提交来源；部件被移除时清残留攻击判定。

用户补充（2026-10-01）：咬击、手剑等动作有配套动画/美术资源，之后补充。当前青色咬击和金色剑光仅独测占位，不作为最终表现；资源到齐后复用动作/真实状态接入，动画与业务保持单一伤害来源。具体命中帧尚未由本次补充冻结，若从即时改为延迟判定，须同步处理暂停、死亡、失去手臂与过期回调。

### 12.2 地形危险

地刺沿用可调长条椭圆Trigger与击退方向，正式接扣血。普通地刺击退不是固定击退距离；落坑另由失败区检测。

共享受伤系统负责扣血、保护与死亡。落坑同次事件不可与多处重叠Trigger重复扣血；生命代价则独立于伤害保护，不能被无敌抵消。

### 12.3 胜负

C14：玩家存活碰触最顶部绿色大门后胜利，不检查精英死亡、不额外支付传送费用。立即完整白屏，再渐显结局图。角色生命归零优先判失败，无同归于尽胜利；支线完成或再生不改变此规则。

出口不要求集齐身体，不再收最后一次舍弃。死亡新局清空构筑、历史、负面、候选、机关、敌人、挑战与锁，从头部教学开始。

> In pawgatory, you begin as just a dog's head and gradually regrow your body. Legs grant a double jump, a tail grants a dash, and arms let you wield a sword.
